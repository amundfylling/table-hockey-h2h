# Table Hockey H2H

A Streamlit app for exploring head-to-head results in table hockey tournaments.

## Getting started

Install the requirements and run the app:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Use the provided devcontainer for a ready-made environment.

## Features

- Pick any two players and see wins, losses and goal statistics
- Separate tabs for round-robin and playoff results
- Charts for yearly win rates and goal differences
- Data loaded from `combined_matches.parquet`
